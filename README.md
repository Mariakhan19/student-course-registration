# Student Course Registration System

## Project Overview

Student Course Registration System is a containerized web application developed using Python and Docker technologies.

The application allows students to access a course registration interface through a web browser while demonstrating DevOps deployment concepts using Docker, Docker Compose, GitHub Actions, Jenkins, Terraform, and Microsoft Azure.

## Docker Compose

Run locally using:

```bash
docker compose up --build
```

---

## Docker Swarm

Deploy using:

```bash
docker swarm init
docker stack deploy -c docker-compose.yml student-app
```
